T轉道場

一個俄羅斯方塊（Tetris）知識講義站。從 1984 年的蘇聯電腦室、T轉的三角規則，到 13 歲玩家讓 NES 當機——每一篇都是「讀完就學會一個概念」的小講義，附盤面圖與道場小測驗。

這個網站怎麼繼續長大？

  1. 所有規則寫在 AGENTS.md（Claude Code 透過 CLAUDE.md 讀取同一份）。
  2. 新增講義：複製 articles/_template.html → 命名為 NN-slug.html → 在 data/articles.js 登記一筆。
  3. 首頁卡片、分類、上一篇／下一篇、盤面圖全部自動產生，不需要改首頁。
